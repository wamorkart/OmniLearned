\subsection{Teacher Model}
\label{sec:teacher}

\begin{itemize}
    \item Teacher is \textbf{PET2}, the OmniLearned backbone: local $k$NN
    interaction blocks ($K{=}15$) + global multi-head self-attention over
    per-particle tokens.
    \item \emph{Large} config: 28 transformer blocks, 4 local-interaction
    heads, \texttt{base\_dim}$=1024$, 32 attention heads.
    \item Fine-tuned directly on top tagging, checkpoint tag
    \texttt{fine\_tune\_top\_l}.
    \item Frozen for every KD run in this report, including the DeepSets
    student.
\end{itemize}

\subsection{Distillation Pipeline}
\label{sec:pipeline}

\begin{itemize}
    \item Teacher logits computed once, offline, on train/val splits
    (\texttt{omnilearned evaluate}), cached as per-event \texttt{.npz}.
    \item Converted to companion H5 files aligned to train/val events
    (\texttt{build\_teacher\_h5.py}); training reads cached logits, never
    re-runs the teacher.
    \item Student trained with
    $\mathcal{L}=\alpha\mathcal{L}_{\mathrm{CE}}+\beta T^2 D_{\mathrm{KL}}(\hat y/T\,\|\,\hat y_{\mathrm{teacher}}/T)$,
    default $\alpha{=}0.5,\beta{=}0.5,T{=}4$.
    \item Evaluated on the held-out 404{,}000-event test split
    (\texttt{omnilearned evaluate --arch deep-sets}): Accuracy, AUC,
    $1/\mathrm{FPR}_{50\%}$, $1/\mathrm{FPR}_{30\%}$.
\end{itemize}

\subsection{DeepSets Student Architecture}
\label{sec:deepsets-arch}

\begin{itemize}
    \item Permutation-invariant Deep Sets classifier,
    $f(X)=\rho(\operatorname{pool}_{x\in X}\phi(x))$: per-particle embedding
    $\phi$ (\texttt{DeepSetsBody}) + global classifier $\rho$
    (\texttt{DeepSetsHead}), masked mean-pooling as the only
    order-discarding op.
    \item Input: 4 raw kinematic features/particle, zero-padded, mask
    $m_n=\mathbb{1}[x_{n,2}\neq0]$; norm is \texttt{DynamicTanh}
    ($\tanh(\alpha x)\odot\gamma$), activation GELU.
    \item Three original size presets (small/medium/large), later extended
    below ``small'' (Section~\ref{sec:deepsets-size-scan}).
    \item \texttt{DynamicTanh} and GELU are non-standard for hls4ml/QONNX;
    a hardware variant would swap in BatchNorm + ReLU.
\end{itemize}

    \end{tabular}
    \caption{DeepSets ablations, same 404{,}000-event test split.}
    \label{tab:deepsets-ablations}

\begin{itemize}
    \item Pure KD ($\alpha{=}0$) \emph{hurts} the DeepSets student --
    opposite of the pattern seen for PET2-architecture students.
    \item Lower weight decay (0.05) also hurts, contradicting the
    over-regularization hypothesis.
    \item Both ablations underperform the mixed-loss, wd$=0.5$ baseline on
    every metric.
    \item \texttt{a05\_T4} (mixed CE+KD, wd$=0.5$) remains the reference
    checkpoint for downstream FPGA/quantization work.
\end{itemize}

    substitute going forward.
    \item Two independent-seed replicates each of CE-only and small-teacher
    were in flight at time of writing; treat sub-point differences above as
    provisional.
\end{itemize}

    latency for a fixed-latency FPGA trigger budget.
\end{itemize}

\subsection{Post-Training Quantization (PTQ)}
\label{sec:deepsets-ptq}

\begin{table}[h]
    \centering
    \small
    \begin{tabular}{lcc}
        \toprule
        Config & distillnet (10{,}981) & small \texttt{a05\_T4} (298{,}887) \\
        \midrule
        float32 (no quantization) & 92.85\% / 0.9800 & 93.30\% / 0.9828 \\
        8-bit PTQ  & 82.90\% / 0.9151 ($-$9.95 pt) & 89.70\% / 0.9613 ($-$3.60 pt) \\
        6-bit PTQ  & 79.64\% / 0.8771 & 86.98\% / 0.9358 \\
        4-bit PTQ  & 49.19\% / 0.5123 (random) & 51.39\% / 0.5261 (random) \\
        \bottomrule
    \end{tabular}
    \caption{Post-training quantization (percentile-calibrated), accuracy /
    AUC.}
    \label{tab:deepsets-ptq}
\end{table}

\begin{itemize}
    \item Naive min/max calibration fails badly (one extreme-$p_T$ jet
    blows up the scale); percentile clipping (0.1--99.9\%) recovers
    $\sim$5 accuracy points at 8-bit.
    \item Even so, 8-bit PTQ still costs 3.6--10 accuracy points depending
    on model size.
    \item 4-bit PTQ collapses to random for both sizes.
    \item \textbf{Plain PTQ is not viable at any useful bit width} --
    quantization-aware training is necessary, not optional.
\end{itemize}

        8-bit PTQ (percentile)        & 82.90\% & 0.9151 & 19.5  & 45.2  \\

    \caption{8-bit QAT vs.\ PTQ vs.\ float32 baseline, distillnet student.}
    \label{tab:deepsets-qat}
\end{table}

\begin{itemize}
    \item Brevitas \texttt{QuantLinear} layers warm-started from the
    trained float32 weights (not random init), same KD loss/teacher kept
    during fine-tuning.
    \item 8-bit QAT closes almost the entire PTQ gap: accuracy drop shrinks
    from 10.0 points to 0.27 points.
    \item Model is not fundamentally quantization-hostile -- it just needs
    weights adapted to the quantization grid via fine-tuning.
    \item No FPGA synthesis run yet; next step is QONNX export (Brevitas)
    $\to$ \texttt{hls4ml} for real LUT/DSP/BRAM/latency numbers.
\end{itemize}

\begin{itemize}
    \item Our \texttt{fine\_tune\_top\_l} teacher reproduces the paper's
    published ``OmniLearned-L'' reference numbers closely -- a clean
    external cross-check.
    \item Pure-KD small student (2.71M params, no pretraining) beats every
    from-scratch model in their comparison, including L-GATr, and beats
    their 48M-param, 100M-jet-pretrained headline result on
    $1/\mathrm{FPR}_{30\%}$.
    \item Pure KD inherits the teacher's unusually steep rejection-curve
    tail almost intact; mixed KD only partially does -- this is why we win
    at 30\% efficiency but lose at 50\% (where their equivariance prior
    wins instead).
    \item Our DeepSets/FPGA students fall outside this paper's comparable
    parameter range, and neither this paper nor its quantization companion
    reports real FPGA synthesis numbers -- same gap our planned
    \texttt{hls4ml} step would fill.
\end{itemize}
